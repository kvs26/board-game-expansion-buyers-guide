# Research batch 14 — 2026-10-08

Game: Memoir '44 (Days of Wonder; base row is Memoir '44 Refresh, $69.99). 6 expansions covered.

## Sources and gotchas
- Years: BGG linked-items API (api.geekdo.com, expansion list for object 10630). Contents: Wikipedia (https://en.wikipedia.org/wiki/Memoir_%2744).
- Prices: Asmodee store products.json for Terrain Pack, Winter-Desert Map, Through Jungle and Desert, Tigers in the Snow and the base game. Eastern Front and Breakthrough Kit are not in the store; I used Amazon's List Price ($49.99, $59.99) as MSRP. Amazon street prices were lower.
- Amazon: curl searches were throttled, so ASINs came from searches in the browser. Titles were checked on each /dp page in the browser; plain curl returned HTTP 200 but often no `<title>`.
- Verified ASINs: B0002TV2NS (base), B000H7KXHG, B000H7MM7K, B000H7NW9W, B003H05K6O, B078WTQY3K, B0D9BRZFBC.
- Tigers in the Snow ASIN is the current Asmodee reprint; the original release was 2009.
- bing.com via curl returned nothing; used Amazon search in the browser.
